# Kubernetes + Flask + Redis Demo

Проект демонстрирует развертывание веб-приложения на Flask и Redis в Kubernetes с использованием Minikube. Приложение позволяет управлять списком аниме через REST API.

## Требования
- Docker
- Minikube
- kubectl

## Prerequisities.sh

Все необходимые компоненты можно установить, запустив следующий скрипт:

```bash
./prerequisites.sh
```

## Запуск

Как только необходимые компоненты будут установлены, весь стек можно будет развернуть, выполнив:

```bash
./launch.sh
```

## Пример использовани

```bash
./test.sh
```
